# Collaborative AI агенты в shared workspaces

**Дата:** 2026-06-24

**Оценка:** СДВИГ
**Уверенность:** высокая

## Что меняется в экосистеме
Проект переносит парадигму с облачной централизации агентов на локальную федеративную архитектуру, где люди и AI синхронизируются через shared workspaces вместо отправки задач в облако. Это переопределяет границу контроля: вместо модели "пользователь → облачный API → результат" появляется модель "локальный daemon + collective workspace = суверенная агентная координация".

## Аргументация
Проект структурно решает две критические проблемы экосистемы одновременно: суверенитет кода (self-hosted) и координацию множественных агентов (collaborative). Это не просто улучшение UI или добавление фичи, а смена того, как организуется доверие и контроль в агентных системах на уровне инфраструктуры.

## Фальсифицируемая гипотеза
**Если права:** Через 12 месяцев появятся enterprise-адаптации платформы, где shared workspaces станут стандартом для inter-agent communication вместо прямых API-вызовов между облачными сервисами.
**Если ошиблась:** Проект останется нишевым инструментом с <5K активных пользователей, не став эталонным паттерном для других платформ агентной координации.
