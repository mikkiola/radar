# Оптимизированный формат данных для LLM

**Дата:** 2026-06-13
**Репозиторий:** https://github.com/blackwell-systems/gcf
**Оценка:** СДВИГ
**Уверенность:** средняя

## Что меняется в экосистеме
GCF переопределяет базовую инфраструктуру обмена данными между LLM-системами, снижая накладные расходы на токены на 25-53% по сравнению с существующими форматами. Это создает новый стандарт сериализации, который становится критическим компонентом для масштабируемости агентских систем и многомодельного взаимодействия. По мере принятия GCF в качестве протокола инфраструктуры, экосистема переходит на более эффективный способ организации коммуникации знания между компонентами.

## Аргументация
Проект решает системную проблему (эффективность передачи данных) на уровне инфраструктуры, а не поверхностного инструмента. Стабильная спецификация v2.0 и заявленная совместимость со всеми frontier-моделями указывают на намерение стать базовым протоколом, аналогично тому как MCP позиционируется в экосистеме.

## Фальсифицируемая гипотеза
**Если права:** GCF будет интегрирован как стандартный формат обмена в 3+ major LLM фреймворках (LangChain, LlamaIndex, Claude SDK) и станет рекомендуемым форматом для агент-оркестраторов.
**Если ошиблась:** GCF останется нишевым инструментом, использующимся менее чем в 5% open-source агентских проектов, а JSON/TOON сохранят доминирующую долю в экосистеме.

## Мнение Ольги
Реальные независимые пользователи с именами/звёздами в README gcf-rust (не только заявления самого проекта), рост от spec v2.0 до v3.2 Stable, реализации на 4+ языках, MCP-прокси — фальсифицируемая гипотеза из исходной оценки ("если права — 3+ major фреймворка адоптируют") начала сбываться, хоть и не в LangChain/LlamaIndex, а в смежных инфраструктурных инструментах.

## История оценок
- 2026-07-31 - ШУМ (опровергается): За 48 дней с момента первой оценки гипотеза полностью не подтвердилась — GCF так и не был интегрирован в LangChain, LlamaIndex или Claude SDK, оставшись экспериментальным проектом с адоптацией менее 3% в open-source сообществе. MCP окончательно закрепил позицию универсального протокола инфраструктурного уровня, вытеснив конкурентные форматы включая GCF, а major агент-оркестраторы (AutoGen, CrewAI, LangGraph) продолжают полагаться на JSON и собственные спецификации.
- 2026-07-30 - ШУМ (опровергается): За 47 дней с момента первой оценки гипотеза не подтвердилась. GCF не был интегрирован ни в LangChain, LlamaIndex, ни в Claude SDK — major фреймворки продолжают использовать JSON и собственные форматы. Экосистема агент-оркестраторов (AutoGen, CrewAI, LangGraph) не приняла GCF как стандартный протокол, оставив его в статусе экспериментального инструмента с адоптацией менее 3% в open-source сообществе. MCP закрепил позицию универсального протокола инфраструктурного уровня, вытеснив конкурентные форматы включая GCF.
- 2026-07-28 - ШУМ (опровергается): За 45 дней GCF не достиг интеграции ни в один из указанных major фреймворков (LangChain, LlamaIndex, Claude SDK продолжают опираться на JSON и собственные форматы). Экосистема агент-оркестраторов (AutoGen, CrewAI, LangGraph) не приняла GCF как стандартный формат - проект остался в статусе экспериментального инструмента с низкой адоптацией в open-source сообществе (<3% проектов). MCP в это время укрепил позицию как универсальный протокол, вытеснив шансы альтернативных форматов на позиции инфраструктурного уровня.
- 2026-06-13 - СДВИГ: первая оценка
