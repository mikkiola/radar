## Суть
Веб-браузер превращается из пользовательского инструмента в стандартизированный модульный компонент агентной инфраструктуры, делая любой веб-сервис автоматизируемым без официальных API.

## Если права
Появятся де-факто стандарты браузерного MCP-слоя, большинство агентных фреймворков будут включать браузерный адаптер по умолчанию, а веб-скрапинг через API уступит место агентной браузерной автоматизации.

## Если ошиблась
Сайты начнут активно блокировать агентный трафик, веб-сервисы массово откроют нативные API для агентов, а браузерный подход останется нишевым workaround.
