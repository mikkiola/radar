# Оценка: n8n-io/n8n

**Дата:** 2026-06-10
**Репозиторий:** https://github.com/n8n-io/n8n
**Оценка:** СДВИГ
**Уверенность:** высокая

## Что меняется в экосистеме
n8n переходит от платформы автоматизации рабочих процессов к инфраструктурному слою для координации AI-агентов через стандартизированные интеграции. Это означает переорганизацию того, как знание о доступных инструментах и сервисах распределяется между агентами — не через proprietary APIs, а через открытые протоколы вроде MCP. Ценность платформы смещается с создания workflow'ов для людей на создание координационного слоя для экосистемы AI-инструментов.

## Аргументация
n8n с native AI capabilities + fair-code моделью становится ключевым узлом для преобразования фрагментированного ландшафта инструментов в единую координируемую систему. Это фундаментальное изменение инфраструктурного уровня, а не просто еще один workflow-инструмент с AI-фичами.

## Фальсифицируемая гипотеза
**Если права:** Основные облачные платформы (AWS/Google Cloud/Azure) интегрируют n8n как native orchestration layer для управления multi-agent системами, и MCP становится стандартом де-факто для определения agent capabilities в enterprise.
**Если ошиблась:** n8n остается нишевым инструментом для интеграций с добавленными AI-фичами, но не становится критической инфраструктурой для координации независимых AI-агентов в экосистеме.
