## Что именно меняется в экосистеме
GitHub переносит контроль над своим API в Model Context Protocol. AI агенты становятся первоклассными участниками экосистемы разработки — наравне с людьми, а не как внешние инструменты.

## Аргументация
Официальный MCP сервер от GitHub — не эксперимент сообщества, а архитектурное решение самой платформы. Это означает что GitHub ставит на агентный доступ как основной интерфейс будущего.

## Критерий пересмотра
Я изменю оценку если: через год MCP остался экспериментальным слоем и основной трафик к GitHub API идёт через REST как прежде.
