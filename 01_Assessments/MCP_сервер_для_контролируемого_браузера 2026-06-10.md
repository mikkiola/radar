# MCP сервер для контролируемого браузера

## Что меняется в экосистеме
Hyperbrowser MCP Server стандартизирует способ подключения ИИ-агентов к живому веб-браузеру через MCP протокол, превращая браузер из инструмента в модульный компонент агентной инфраструктуры. Это меняет архитектуру: вместо каждого агента-фреймворка писать свой адаптер для браузера, все используют единый стандартный интерфейс. Тем самым закрепляется MCP как де-факто протокол для расширения возможностей ИИ-агентов за пределы текста.

## Аргументация
Проект находится в пересечении двух мощных трендов — стандартизации агентной инфраструктуры (MCP) и веб-автоматизации (browser-use). Он не просто улучшает инструмент, а переопределяет архитектурное место браузера в экосистеме агентов, делая его заменяемым компонентом вместо proprietary расширения.

## Фальсифицируемая гипотеза
**Если права:** Основные фреймворки агентов (LangChain, crew.ai, n8n) интегрируют Hyperbrowser MCP Server как стандартный способ веб-доступа, вытесняя собственные браузер-интеграции.
**Если ошиблась:** Фреймворки продолжают развивать собственные встроенные браузер-адаптеры вместо перехода на MCP стандарт, оставляя Hyperbrowser нишевым инструментом.
