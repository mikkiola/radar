# Open-source база данных для агентов

**Дата:** 2026-06-10
**Репозиторий:** https://insforge.dev/
**Оценка:** ШУМ
**Уверенность:** средняя

## Что меняется в экосистеме
InsForge позиционируется как альтернатива Supabase для агент-ориентированных приложений, но это скорее переупаковка существующих паттернов (self-hosted БД + API) под новый маркет-слоган "agent-friendly" без принципиального изменения инфраструктурных парадигм.

## Аргументация
Проект представляет собой инкрементальное улучшение stack'а (база данных + backend как сервис), а не переопределение того, как агенты взаимодействуют с персистентностью. Истинный сдвиг будет, когда инфраструктура переедет на агент-нативные протоколы типа MCP, а не просто адаптирует старые слои под новых пользователей.

## Фальсифицируемая гипотеза
**Если права:** InsForge останется нишевым инструментом с <5K monthly active users и не станет стандартной инфраструктурой для agentloops через 12 месяцев.
**Если ошиблась:** InsForge интегрирует MCP как первичный протокол взаимодействия и получит массовое внедрение в major agent frameworks (LangChain, CrewAI), став структурообразующей инфраструктурой.

## Правка человека
 ШУМ → СДВИГ, сильно подтверждено. 31.07.2026 Ключевые факты:

1. **MCP интегрирован как первичный протокол** — не просто добавлен, а стал архитектурным ядром: "We designed our entire MCP stack for agent oriented development". Remote MCP Server запущен в феврале 2026, до этого был только локальный
2. **99% операций теперь от агентов, не людей** (InsForge 2.0 launch, март 2026) — "Provisioning, configuration, migrations, and runtime actions are executed by agents, not through dashboards, CLIs, or hand written scripts" — это ровно то самое переопределение, о котором говорила аргументация исходной оценки, только Haiku посчитала это недостаточным, а по факту это случилось
3. **Количественные бенчмарки против прямого конкурента Supabase**: 47.6% pass rate vs 28.6% у Supabase MCP, +14% точности, 1.6x быстрее, 30% меньше токенов — конкретные, воспроизводимые цифры (MCPMark benchmark), не голословный маркетинг
4. **Реальный масштаб**: 12,530 звёзд на главном репозитории, 1,100 форков — далеко за пределами "нишевого инструмента"
5. Органические положительные отзывы пользователей о реальном использовании в продакшене (не просто цитаты с лендинга — конкретные имена, конкретные кейсы использования)
